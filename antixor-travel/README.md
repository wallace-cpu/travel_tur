# Antixor Travel & Tours — Landing Page Cinematográfica

Projeto em HTML, CSS e JavaScript puro com:

- GSAP 3 + ScrollTrigger
- Three.js para partículas 3D no background
- Parallax em eixo X/Y
- Entradas cinematográficas dos textos e imagens
- Cards de destinos com movimento no scroll
- Hero com busca
- Seção de pacote
- História da marca
- Depoimentos
- CTA final
- Layout responsivo para desktop, tablet e mobile

## Estrutura

```text
antixor-travel/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    └── travel-reference.png
```

## Executar

Abra `index.html` em um servidor local. Para VS Code, pode usar Live Server.

As bibliotecas GSAP e Three.js são carregadas por CDN, então é necessário internet para as animações.

## Deploy

O projeto é estático e pode ser publicado diretamente em Vercel, Netlify, GitHub Pages ou HostGator.

## Observação

As fotos dos cards são carregadas do Unsplash por URL para manter o projeto leve. Para produção, substitua por imagens próprias/licenciadas.
